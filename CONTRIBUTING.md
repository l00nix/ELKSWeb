# Contributing

ELKSWeb is an experimental original C browser targeting ELKS and the 8088 instruction set. Keep runtime dependencies and memory use small. MicroWeb is a separately executed reference; do not copy its C++ source or assets into the browser.

For a bug report, include the ELKS version, emulator/hardware and CPU speed, graphics mode, network adapter/configuration, URL or minimal local fixture, exact steps, expected/actual behavior, and screenshot where useful. Remove credentials and private URLs from reports.

Changes should include focused verification appropriate to the behavior. Host tests alone do not establish native correctness or 8088 usability. Record timing and memory separately from functional and visual results. Do not label a screenshot or successful request as full parity.

Current priorities are documented in [STATUS.md](docs/STATUS.md). Public-beta readiness has not been reached.

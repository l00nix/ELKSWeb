Keyboard help

These controls work in both browsers. Hold Ctrl while pressing the letter. Function keys are optional. This page works offline and has no images.

Browsing

Ctrl-L (or F6): edit the address. Enter opens it; Escape cancels editing.
Ctrl-R (or F5): reload the current page.
Ctrl-D: redraw the existing page, without downloading or decoding images again.
Ctrl-V (or F2): invert monochrome colours / switch the colour theme.
Ctrl-T (or F3): show or hide browser bars.
Ctrl-G: open this help page. Ctrl-B returns to the previous page.
Ctrl-B / Ctrl-F: back / forward in browsing history.

Links, forms and scrolling

Tab / Ctrl-N: select the next link or control.
Shift-Tab / Ctrl-W: select the previous link or control.
Enter: follow a link, activate a control or submit a text field.
Space: activate a selected checkbox, radio button or list.
Arrow keys: scroll, move a text cursor or choose list/radio options.
Page Up / Page Down: scroll a screen. Home / End: beginning / end.
Backspace / Delete: edit text. Backspace outside a text field goes back.
Escape: cancel an address edit, download prompt or open list; otherwise exit. During a transfer it cancels the transfer.

Editing and downloads

Reload, help and history shortcuts operate outside address editing, download prompts and open lists. Finish or cancel those controls first. In a form text field, these navigation commands can leave the page; unsaved form entries may be lost. Ctrl-D only repaints and preserves edits. It also works in editing controls.

In a download prompt, type a filename and press Enter to save. Tab / Ctrl-N and Shift-Tab / Ctrl-W switch between the filename and Download button. Escape cancels. Ctrl-L switches to the address field.

Keyboard compatibility

Ctrl-I is Tab and Ctrl-H is Backspace; neither is a separate browser command. Ctrl-A is reserved by some Nano-X servers for ending the graphics session. Ctrl-P is used by some servers for Print. Ctrl-S / Ctrl-Q may control terminal flow. Nano-X receives keys through its server; key support depends on that input driver.

The HP cooked-key setting and direct-console keyboard/mouse settings are unchanged. The Nano-X server supplies WebNX keyboard and mouse input.

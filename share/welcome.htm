ELKSWeb and WebNX 0.6.2dev - two ways to browse

elksweb browses directly from the graphics console. webnx browses through Nano-X. Both open this page and use the same browser engine.

Browse: press Ctrl-L, enter a hostname or HTTP address, then press Enter. Select links with Tab and Enter.

Common controls

Tab / Shift-Tab next / previous link or control. Enter activate.
Arrows / Page Up / Page Down scroll. Home / End beginning / end.
Backspace back. Escape exit or cancel editing.
Ctrl-L edit the address. The top-left buttons go back and forward.

Function keys, where supported: F6 address, F5 reload, F2 invert / dark theme, F3 show / hide browser bars. Nano-X key availability depends on its server and input driver.

Choose how to browse

Direct console: run elksweb and choose a display mode. Enter alone chooses CGA. Or run elksweb -video cga for a monochrome display. VGA, Tandy and PCjr colour modes require compatible hardware and ELKS setup. HP cooked-key and PPC/HP serial-mouse settings are retained.

Nano-X: run webnx with a compatible Nano-X server installed. Nano-X supplies the display, keyboard and mouse. Its client library can start an installed server; the server handles session shutdown and console restoration. Closing WebNX in an existing desktop leaves other clients running.

Both accept a URL or local filename, -invert and -noimages. Open /lib/web/welcome.htm to return here. Use exec before your launch command to replace the waiting shell and save its memory.

Development and testing

One nightly package installs both browsers and these pages: ept install -n elksweb. Users of the old split packages must follow /lib/web/nanox.txt for the one-time migration before upgrading.

0.6.2dev retains faster scrolling, VGA colour and GIF workspace improvements. The physical PC-98 console reports and intermittent Nano-X logo rendering remain open. No new EMS support or low-memory browsing guarantee is included.

What to expect

HTTP and local HTML or text are supported. GIFs display; JPEG and PNG use placeholders. HTTPS, CSS and JavaScript are not supported. Large pages and images may exceed available memory; loading on an 8088 can take time.

This page works offline. Internet links need working ELKS networking. Configure the network before opening HTTP pages.

ELKSWeb 0.1 - a small browser for ELKS

Start browsing: press F6 or Ctrl-L, type an HTTP address, then press Enter. Or select a link below with Tab and press Enter.

Keyboard help

Tab / Shift-Tab Select the next / previous link or control.
Enter Follow the selected link or activate a control.
Arrows / Page Up / Page Down Scroll the page.
Home / End Jump to the beginning / end.
Backspace Go back. The top-left buttons go back and forward.
F5 Reload. Escape Exit, or cancel a load when input is checked.
F2 Invert black and white. F3 Show or hide the browser bars.

Local files and display

To return here, enter file:/root/welcome.htm in the address field. Use file:/path/page.htm to open another local page.

Starting elksweb without options shows the display selector. Choose a listed mode and press Enter. Enter alone chooses CGA; Q quits. You can also start with elksweb -video cga, -video ega or -video vga.

What to expect

ELKSWeb reads HTTP and local HTML or text. GIF images are displayed; JPEG and PNG dimensions are used for layout, with placeholders. HTTPS, CSS and JavaScript are not supported. Large pages may reach memory limits, and loading on an 8088 can take time.

This help page works offline. The search and news links need a working ELKS network connection; their availability depends on the sites.

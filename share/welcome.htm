Getting around

F6 / Ctrl-L Enter an HTTP address or local file path.
Tab / Shift-Tab Select a link or control. Enter Open it.
Arrows / Page Up / Page Down Scroll. Home / End Jump.
Backspace Go back. F5 Reload. Escape Exit.

F2 Invert the screen. F3 Show or hide browser bars.

ELKSWeb 0.6dev1-nx2 - Nano-X experiment

A separate experimental browser using Nano-X for display, keyboard and mouse. Thanks to astrobleem for the Nano-X client and colour support.

Browse: press Ctrl-L, enter a hostname or HTTP address, then press Enter. Use Tab and Enter to follow links.

Controls

Arrows scroll. Backspace goes back. Escape cancels editing or exits the browser. Function keys and Page Up/Down depend on the Nano-X server's keyboard driver; some older ELKS servers do not translate all of them.

Testing notes

This nightly installs as webnx alongside the normal elksweb. It requires an existing Nano-X server built for your hardware. No kernel or EMS change is included.

The physical PC-98 text-console overlap and apparent exit hang still need investigation. Please report your kernel/server versions, launch command, memory readings and whether the keyboard and text console work after exit.

Launch and diagnostic instructions are installed in /lib/webnx/readme.txt. Optional file logging: export ELKSWEB_NX_LOG=/tmp/webnx.log before launch.
